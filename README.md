# Duck-Tac-Toe

Play tic-tac-toe live with your Ducky — board lives inside the chat (collapsible aside) + Live voice, MCP tools, and a skill for real-time play.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`ducktactoe`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/ducktactoe-1.0.16.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
